# Fraunces

Self-hosted upright variable Fraunces by The Fraunces Project Authors, SIL OFL 1.1; see [OFL.txt](OFL.txt). Source: [undercasetype/Fraunces](https://github.com/undercasetype/Fraunces), commit `7ccdec31c6028118dce3e47fe864e3744460371d`, `fonts/variable/Fraunces[SOFT,WONK,opsz,wght].ttf`.

The WOFF2 is a lossless format conversion using FontTools 4.68.0 and Brotli 1.2.0, without subsetting or outline/axis changes. Axes: opsz 9–144, wght 100–900, SOFT 0–100, WONK 0–1. The showcase uses opsz 14, SOFT 0, WONK 0 for restrained small-size reading, with normal CSS font weights. Fraunces is a serif/display face, not a sans-serif. Only the shared Artbin-inspired theme's serif role changes; production Artbin and existing sans-serif roles do not.

The local CSS and preload avoid external font services. This font is licensed separately from application source.
