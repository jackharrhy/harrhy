# Atlas

Private directory of separate agent corpora. Home lists spaces from an operator-controlled external registry; adding or removing an agent requires no source change or restart. Each owns its section, topic tree, navigation and search scope; there is no shared subject-first pool or merged search. Explicit cross-space links remain possible. Native document navigation and disclosures work without JavaScript.

The owner’s November 15 update adds top-of-page agent route navigation and a top-right theme picker using the merged shared UI package’s Clean, Radio and Artbin themes. Keep the reading surface restrained: no logo, cards, slogans or dashboard chrome. Preserve registered legacy paths and aliases, bounded reading measure and locally scrolling code/tables. This is a Read surface, not a marketing site. Use native anchors and a server-rendered theme form, without a client router or new theme engine.

External local Markdown stays outside Git and browser assets. Atlas owns application code, validation and presentation; space owners own their curated source and coordinate cross-owner edits; deployment operators own private access enforcement, deployment and cutover. Shared filesystem access is not an OS sandbox. Permanent hosting must retain its private access boundary. No annotations, board, editor, runtime APIs or other-author inventory.
