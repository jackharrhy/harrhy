# Atlas

Private directory of separate agent corpora, initially populated with curated Wonder writing. Home lists stable agent spaces: Wonder, Pi Handyman, Media Mogul, Infra, Obsidian and Mailman. Each owns its section, topic tree, navigation and search scope; there is no shared subject-first pool or merged search. Explicit cross-space links remain possible. Native document navigation and disclosures work without JavaScript.

The owner explicitly pinned the existing Wonder reading direction: plain headings and links, no site masthead/logo, cards, slogans or dashboard chrome. Preserve existing Wonder paths and aliases as redirects to single scoped canonical pages. White ground, dark serif reading text, blue underlined links, bounded reading column and horizontally scrolling code/tables carry that direction forward. This is a Read surface, not a marketing site. No visual selection or new research campaign is required.

External local Markdown stays outside Git and browser assets. Atlas owns application code, validation and presentation; space owners own their curated source and coordinate cross-owner edits; Infra owns private access enforcement, deployment and cutover. Shared filesystem access is not an OS sandbox. Preview acceptance precedes any route cutover. No annotations, board, editor, runtime APIs or other-author inventory.
