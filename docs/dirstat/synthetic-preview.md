# Synthetic scanner exercise

`apps/dirstat/preview/record.mjs` generates a disposable archive beneath its
working directory and invokes the Rust scanner. Use a private writable scratch
directory and provide the scanner binary and destination recording file as
arguments. The recorder accepts no external scan root.

Protocol 3 collapses dependency trees, Python environments, and verified CMake
output into named summaries. An ordinary build directory keeps its detail.
Allocated regular-file bytes use Linux `st_blocks × 512`. Skipped and omitted
records prevent publication as complete, and an aborted recording cannot replace
a valid result. Candidate labels are advisory; there is no cleanup action.

The recorder caps entries, bytes, duration, and output size. In scratch, set
`HARRHY_DIRSTAT_MAX_ENTRIES=3` to exercise a bounded abort without filling disk.
This exercise needs no network listener and does not deploy a preview.
